# 破例登记册

宪法第 31 条：确需违宪时，必须在此登记。三条硬性要求——**无到期日的破例不予登记**；到期未偿还的破例自动升级为阻塞项；同一破例不得续期超过两次。禁止口头破例。

每条破例一个文件，命名 `EX-<年>-<序号>-<短名>.md`，必备字段：

| 字段 | 要求 |
|---|---|
| 违反的条款 | 条号 + 一句话说清违反了哪一句 |
| 理由 | 为什么现在不能对齐（"工期紧"不是理由） |
| 影响面 | 规则 / 表 / 工具 / 插件 |
| **到期日** | 必填；没有就不登记 |
| 偿还计划 | 具体动作 + 负责人 + 预估工作量 |
| 批准人 | 第 29 条批准人；口头批准无效 |

状态流转：`待批准` → `生效` → `已偿还` / `已升级`（到期未偿）。
